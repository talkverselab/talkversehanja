# 폰다운키즈업 / 노폰키즈 홈페이지 PNG 10장

디자인 톤: 밤하늘 남색(#16213f), 별 노랑(#ffd36e), 산호색(#f2765b), 크림(#fff4cf). 세련되고 따뜻한 느낌.

## 파일 목록과 용도

1. 01-hero-banner.png : 홈페이지 메인 히어로 배너. "폰다운, 키즈업!" 슬로건과 내려놓은 스마트폰.
2. 02-logo-phonedown.png : "폰다운키즈업" 워드마크 로고. 헤더나 브랜드용.
3. 03-logo-nophone.png : "노폰키즈" 앱 워드마크 로고. 앱 아이콘이나 소개용.
4. 04-icon-phonedown.png : 섹션 아이콘 - 폰 다운. 약속 시간 외 사용 안내.
5. 05-icon-notification.png : 섹션 아이콘 - 알림. 부모에게 바로 알림이 가는 기능.
6. 06-sns-slogan.png : SNS용 정사각 카드. "폰다운, 키즈업!" 
7. 07-sns-promise.png : SNS용 정사각 카드. "약속을 지키면 1원도 들지 않습니다."
8. 08-section-banner.png : 섹션 배너. 피쳐폰과 스마트폰, "폰다운, 키즈업!"
9. 09-icon-featurephone.png : 섹션 아이콘 - 피쳐폰. 연락은 피쳐폰으로.
10. 10-icon-kids-up.png : 섹션 아이콘 - 키즈업. 아이들이 성장하는 모습.

## 사용 방법

바이너리 PNG 업로드 제한으로 인해 base64 버전이 있다면 `python decode_pngs.py` 를 실행하여 PNG를 생성하세요.
