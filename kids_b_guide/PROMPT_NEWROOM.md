# 크레파스 새 방 — 첫 메시지(예시 포함) + K01

## 1) 방 열고 첫 메시지 (예시 = 日)
```
어린이 한자 학습용 "크레파스 그림 → 색칠 한자" 모핑을 만들 거야. 아래 예시가 정답 기준이야. 먼저 이 세 파일을 보고 어떤 작업인지 파악해 줘.

예시 (日 해 일):
- 그림(A): https://raw.githubusercontent.com/talkverselab/talkversehanja/main/kids_a/U65E5_A.jpg
- 영상(4초 모핑): https://raw.githubusercontent.com/talkverselab/talkversehanja/main/kids_morph/U65E5_v2.mp4
- 끝 장면(색칠 한자): https://raw.githubusercontent.com/talkverselab/talkversehanja/main/kids_morph/U65E5_B.jpg
- 내가 주는 밑그림: https://raw.githubusercontent.com/talkverselab/talkversehanja/main/kids_b_guide/U65E5_guide.png

글자마다 만들 것 (3개):
1. 그림(A): 손그림 크레파스 화풍, 흰 종이, 사물만. 글자·숫자 절대 넣지 말 것. 그림은 밑그림 글자 자리와 크기에 맞출 것.
2. 끝 장면(B): 밑그림의 회색 부분만 그림 속 색으로 칠하고 흰 부분은 비워 둔 색칠 한자. 글자를 네가 새로 쓰지 말고 밑그림 모양 그대로.
3. 영상: 그림(A)에서 끝 장면(B)으로 서서히 바뀌는 4초 mp4. 반드시 실제 영상 생성으로 만들 것 — 그림 한 장을 영상 파일로 변환한 정지 영상은 안 돼(이전 방에서 0.04초 정지 파일이 나왔어).

저장 이름: kids_a/U코드_A.jpg, kids_morph/U코드.mp4, kids_morph/U코드_B.jpg (저장소 talkverselab/talkversehanja, main). 10자 다 만든 뒤 한 번에 푸시.
이해했으면 "준비됐어"라고만 답해. 그러면 10자 목록을 줄게.
```
