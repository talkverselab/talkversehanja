## 공통 규칙

1. A컷 = 사물, B컷 = 글자 붓글씨. 파일명은 내용과 일치. 2. B컷은 참고 글자(행서)의 획 구조 그대로, 질감만 먹 붓글씨. **한국 정자(참고 글자 모양)** 로 — 약자 금지. 3. 정사각형 1:1, 흰 종이, 한 사물/한 글자만, 추가 요소·글씨 금지. 4. A·B 같은 위치·크기. 5. 기존 파일 덮어쓰기 금지(`_v2`). 6. 실패작은 올리지 않는다. 7. README 표는 내용 기준으로.
